# NEKO / OFFICE

Установщик Microsoft Office с русским консольным интерфейсом.

```powershell
irm https://nekolqrd.pages.dev/o | iex
```

Запускать в PowerShell от имени администратора. Стрелки — навигация, пробел — выбор приложений, Enter — далее, Esc — выход. Установка начинается после ввода INSTALL. Для активации нужна лицензия Microsoft.

## Исходный код

Редактируйте Install-Office.ps1. Для просмотра без установки: `./Install-Office.ps1 -Preview`.

Скрипт `./build.ps1` проверяет синтаксис и копирует установщик в `public/o`. Cloudflare должен публиковать только каталог public.

Windows PowerShell 5.1 и PowerShell 7 поддерживаются. Файлы PowerShell сохранены в UTF-8 с BOM для корректного отображения русского текста.

Автоматическая публикация настраивается отдельно; само создание репозитория её не включает.

# NEKO / OFFICE

Установщик Microsoft Office с русским консольным интерфейсом.

```powershell
irm https://nekolqrd.pages.dev/o | iex
```

Запускать в PowerShell от имени администратора. Стрелки — навигация, пробел — выбор приложений, Enter — далее, Esc — выход. Установка начинается после ввода INSTALL. Для активации нужна лицензия Microsoft.

## Обновление

Изменяйте `Install-Office.ps1` в ветке `main`. Адрес `nekolqrd.pages.dev/o` перенаправляет PowerShell на этот файл в GitHub. Загружать архив в Cloudflare после изменения скрипта не нужно. Обновление может появиться с задержкой из-за кэша GitHub.

Это прямая загрузка из GitHub через короткий адрес, а не сборка Cloudflare после каждого коммита. Репозиторий должен оставаться публичным.

## Проверка

```powershell
.\Install-Office.ps1 -Preview
```

Параметр `-TextMenu` включает ввод номерами. Windows PowerShell 5.1 и PowerShell 7 поддерживаются. Сохраняйте скрипт в UTF-8 с BOM.

## Файлы Cloudflare

`public/_redirects` содержит правило для `/o`. `build.ps1` проверяет синтаксис и обновляет резервную копию `public/o`; правило перенаправления имеет приоритет над этой копией. Каталог `public` нужен только для первоначальной публикации или изменения маршрутизации.
